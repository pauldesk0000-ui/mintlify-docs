This page walks you through running the WishWe mobile app on an iOS Simulator. You'll start the Django backend locally, point the mobile app at it, and launch the app through Expo — all from your Mac.

## Prerequisites

Before you begin, make sure you have the following installed and ready:

- **macOS** — the iOS Simulator is only available on macOS.
- **Xcode** with at least one iOS Simulator runtime installed. You can download both from the Mac App Store or [developer.apple.com](https://developer.apple.com/xcode/).
- **Node.js LTS** (includes npm) — download from [nodejs.org](https://nodejs.org).
- **Python 3.12 or newer** — download from [python.org](https://www.python.org).
- **PostgreSQL database** — a non-production database you can connect to locally. The repository's Docker Compose file is for production deployment and does not start a local database.

## Start the Backend

The mobile app requires a running Django API. Open a terminal, navigate to the repository root, and follow these steps:

<Steps>
  <Step title="Copy and edit the environment file">
    ```bash
    cd backend
    cp .env.sample .env
    ```

    Open `backend/.env` and set the following values for your local database:

    ```bash
    SECRET_KEY=a-long-random-local-secret
    DB_HOST=your-database-host
    DB_NAME=your-database-name
    DB_USER=your-database-user
    DB_PASSWORD=your-database-password
    DB_PORT=5432
    DJANGO_SETTINGS_MODULE=wishwe_api.settings
    ```
  </Step>

  <Step title="Create a virtual environment and install dependencies">
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install --upgrade pip
    python -m pip install -r requirements.txt
    ```
  </Step>

  <Step title="Apply database migrations">
    ```bash
    python manage.py migrate
    ```

    Only run this against a development database you are explicitly allowed to modify. Never migrate a shared or production database without authorization.
  </Step>

  <Step title="Start the development server">
    ```bash
    python manage.py runserver 0.0.0.0:8000 --noreload
    ```

    Leave this terminal running. The backend must stay up while you use the app. You can verify it's healthy by checking `http://localhost:8000/api/health/` — it should return `{"status":"ok"}`.
  </Step>
</Steps>

## Configure the Mobile App

Open a second terminal, then install dependencies and set the API URL:

<Steps>
  <Step title="Install npm dependencies">
    ```bash
    cd mobile
    npm ci
    ```
  </Step>

  <Step title="Set the API URL">
    ```bash
    cp .env.example .env
    ```

    Open `mobile/.env` and set:

    ```bash
    EXPO_PUBLIC_API_URL=http://localhost:8000
    ```
  </Step>
</Steps>

## Launch on iOS Simulator

With both the backend running and the mobile app configured, start Expo:

```bash
npx expo start --ios
```

Expo starts the Metro bundler and automatically opens the app in the available iOS Simulator. On the first run, the Simulator may prompt you to open Expo Go — accept it.

<Note>
  iOS Simulator is only available on macOS. If you're on Windows or Linux, follow the [Android guide](/mobile/android) instead.
</Note>

<Tip>
  If Metro is already running, press `i` in the Metro terminal to open the iOS Simulator without restarting the bundler.
</Tip>
