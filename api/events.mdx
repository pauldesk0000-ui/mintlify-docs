title: "WishWe Events API: Create, List, and Retrieve Events"

description: "Use the WishWe Events API to create wishes and plans, list events in your feed, retrieve a single event, and delete your own events."
---

The Events API is the core of WishWe. It lets you create two types of social events — **wishes** (open-ended ideas without a fixed date) and **plans** (concrete events with a date, time, and participant cap) — and surfaces them in a social feed scoped to a user's friend network. All write endpoints require authentication.

---

## Event Object

All event endpoints return an event object with the following fields:

<ResponseField name="id" type="integer" required>
  Unique identifier for the event.
</ResponseField>

<ResponseField name="event_type" type="string" required>
  The kind of event. One of `wish` or `plan`.
</ResponseField>

<ResponseField name="event_visibility" type="string" required>
  Who can see the event in their feed. One of:
  - `friends-only` — visible only to direct friends of the creator.
  - `f-o-f` — visible to friends and friends-of-friends of the creator (default).
</ResponseField>

<ResponseField name="title" type="string" required>
  Event title. Maximum 50 characters.
</ResponseField>

<ResponseField name="description" type="string">
  A short description of the event. Maximum 200 characters. Defaults to `"No details added by the host."`.
</ResponseField>

<ResponseField name="location" type="string" required>
  The venue or area for the event.
</ResponseField>

<ResponseField name="cover_image" type="string | null">
  URL of the uploaded cover image, or `null` if none was provided.
</ResponseField>

<ResponseField name="category" type="string | null">
  The name of the category assigned to the event (e.g. `"Music"`, `"Sports"`), or `null`.
</ResponseField>

<ResponseField name="creator" type="string" required>
  Username of the user who created the event.
</ResponseField>

<ResponseField name="creator_avatar" type="string | null">
  URL of the creator's profile avatar.
</ResponseField>

<ResponseField name="event_date" type="string | null">
  Date of the event in `YYYY-MM-DD` format. Always present for plans; `null` for wishes.
</ResponseField>

<ResponseField name="event_time" type="string | null">
  Time of the event in `HH:MM` format. Always present for plans; `null` for wishes.
</ResponseField>

<ResponseField name="timeframe_text" type="string | null">
  A human-readable timeframe description (e.g. `"This summer"`). Required for wishes; `null` for plans.
</ResponseField>

<ResponseField name="min_participants" type="integer">
  Minimum number of participants. Defaults to `1`.
</ResponseField>

<ResponseField name="max_participants" type="integer | null">
  Maximum number of participants. Required for plans (minimum value: `2`); `null` for wishes.
</ResponseField>

<ResponseField name="participants_count" type="integer">
  Number of users who have joined the plan. For wishes, reflects the creator's initial interested count.
</ResponseField>

<ResponseField name="interested_count" type="integer">
  Number of users who have marked interest in a wish. For plans, this is always `0`.
</ResponseField>

<ResponseField name="status" type="string">
  Current state of the event. One of:
  - `active` — open and accepting joins or interest.
  - `closed` — the plan has reached its `max_participants` cap.
  - `completed` — the plan has been archived by its creator. Wishes can never have this status.
</ResponseField>

<ResponseField name="available_spots" type="integer | null">
  Remaining spots on a plan (`max_participants - participants_count`). Always `null` for wishes.
</ResponseField>

<ResponseField name="is_full" type="boolean">
  `true` when a plan has reached its `max_participants`. Always `false` for wishes.
</ResponseField>

<ResponseField name="can_join" type="boolean">
  `true` when the event is `active`, not full, and not expired.
</ResponseField>

<ResponseField name="has_share_link" type="boolean">
  `true` if a shareable link has been generated for this event.
</ResponseField>

<ResponseField name="mutual_friend" type="object | null">
  If the event is visible through a friend-of-friend connection, this contains `{ "id": integer, "username": string }` for the mutual friend. `null` if the creator is a direct friend.
</ResponseField>

<ResponseField name="user_participation_status" type="string | null">
  The authenticated user's participation status for this event: `"joined"`, `"interested"`, or `null` if not participating.
</ResponseField>

<ResponseField name="participants_preview" type="array">
  An array of up to 6 participants (joined for plans, interested for wishes). Each item contains `{ "username": string, "avatar": string | null }`.
</ResponseField>

<ResponseField name="expires_at" type="string | null">
  ISO 8601 datetime at which the plan expires (set to 5 minutes after `event_date` + `event_time`). `null` for wishes.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 datetime when the event was created.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 datetime when the event was last updated.
</ResponseField>

## List Events

Retrieve a paginated list of events in the authenticated user's social feed. The feed includes events from direct friends and, by default, friends-of-friends (for `f-o-f` visibility events).

```
GET /api/event/events/
```

### Query Parameters

<ParamField query="type" type="string">
  Filter by event type. Accepted values: `wish`, `plan`.
</ParamField>

<ParamField query="visible" type="string">
  Filter by visibility scope:
  - Omit or pass `all` — returns events from friends **and** friends-of-friends.
  - `friends` — returns only events from direct friends.
</ParamField>

<ParamField query="title" type="string">
  Case-insensitive substring search on the event title.
</ParamField>

<ParamField query="sort" type="string">
  Sort order for the feed:
  - Omit — most recently created first (default).
  - `soonest` — plans sorted by `event_date` and `event_time` ascending.
  - `heat` — sorted by the number of your friends who have joined (plans) or marked interest (wishes), descending.
</ParamField>

### Response

Returns a paginated list of event objects.

## Create a Wish

Create a new wish — an open-ended event idea without a fixed date. The creator is automatically added as the first interested participant.

```
POST /api/event/events/create_wish/
```

### Request Body

<ParamField body="title" type="string" required>
  Event title. Maximum 50 characters.
</ParamField>

<ParamField body="description" type="string">
  Short description of the wish. Maximum 200 characters.
</ParamField>

<ParamField body="location" type="string" required>
  Venue or area for the wish.
</ParamField>

<ParamField body="category" type="integer">
  ID of a category. Retrieve valid IDs from `GET /api/event/category/`.
</ParamField>

<ParamField body="timeframe_text" type="string" required>
  A human-readable timeframe description (e.g. `"This winter"`, `"Sometime in September"`). Required for all wishes.
</ParamField>

<ParamField body="event_visibility" type="string">
  Who can see this wish. One of `friends-only` or `f-o-f`. Defaults to `f-o-f`.
</ParamField>

<ParamField body="min_participants" type="integer">
  Minimum number of interested participants. Defaults to `1`.
</ParamField>

<ParamField body="cover_image" type="file">
  Optional cover image. Must be a valid image file type. Send as `multipart/form-data`.
</ParamField>

<ParamField body="external_link" type="string">
  Optional URL linking to more information about the wish.
</ParamField>

### Response

Returns `201 Created` with the full event object.

```json
{
  "id": 42,
  "event_type": "wish",
  "event_visibility": "f-o-f",
  "title": "Hot Air Balloon Ride",
  "description": "Always wanted to try this with friends!",

  "cover_image": null,
  "category": "Adventure",
  "creator": "jess_w",
  "creator_avatar": "https://cdn.wishwe.online/uploads/avatars/jess.jpg",
  "mutual_friend": null,
  "user_participation_status": "interested",
  "event_date": null,
  "event_time": null,
  "timeframe_text": "This fall",
  "min_participants": 2,
  "max_participants": null,
  "participants_count": 0,
  "interested_count": 1,
  "participants_preview": [],
  "status": "active",
  "available_spots": null,
  "is_full": false,
  "can_join": true,
  "has_share_link": false,
  "expires_at": null,
  "created_at": "2025-07-15T09:00:00Z",
  "updated_at": "2025-07-15T09:00:00Z"
}
```

## Create a Plan

Create a new plan — a concrete event with a fixed date, time, and participant cap. The creator is automatically counted as the first joined participant.

```
POST /api/event/events/create_plan/
```

### Request Body

<ParamField body="title" type="string" required>
  Event title. Maximum 50 characters.
</ParamField>

<ParamField body="description" type="string">
  Short description of the plan. Maximum 200 characters.
</ParamField>

<ParamField body="location" type="string" required>
  Venue or area for the plan.
</ParamField>

<ParamField body="category" type="integer">
  ID of a category. Retrieve valid IDs from `GET /api/event/category/`.
</ParamField>

<ParamField body="event_date" type="string" required>
  Date of the event in `YYYY-MM-DD` format.
</ParamField>

<ParamField body="event_time" type="string" required>
  Time of the event in `HH:MM` format.
</ParamField>

<ParamField body="min_participants" type="integer">
  Minimum number of participants. Defaults to `1`.
</ParamField>

<ParamField body="max_participants" type="integer" required>
  Maximum number of participants. Must be at least `2` and greater than or equal to `min_participants`.
</ParamField>

<ParamField body="event_visibility" type="string">
  Who can see this plan. One of `friends-only` or `f-o-f`. Defaults to `f-o-f`.
</ParamField>

<ParamField body="cover_image" type="file">
  Optional cover image. Must be a valid image file type. Send as `multipart/form-data`.
</ParamField>

<ParamField body="external_link" type="string">
  Optional URL linking to more information about the plan.

## Retrieve an Event

Fetch a single event by its ID.

```
GET /api/event/events/{id}/
```

<Warning>
  Returns `403 Forbidden` if the authenticated user does not have permission to view the event based on the creator's visibility settings and friend graph.
</Warning>

### Path Parameters

<ParamField path="id" type="integer" required>
  The unique ID of the event.
</ParamField>

### Response

Returns `200 OK` with the full event object.

---

## Delete an Event

Permanently delete an event. Only the event creator can perform this action.

```
DELETE /api/event/events/{id}/
```

<Warning>
  All participants are notified when an event is deleted. This action cannot be undone.
</Warning>

### Path Parameters

<ParamField path="id" type="integer" required>
  The unique ID of the event to delete.
</ParamField>

### Response

Returns `204 No Content` on success.

## List Categories

Retrieve all available event categories. This endpoint is public — no authentication required.

```
GET /api/event/category/
```

### Response

Returns `200 OK` with an array of category objects.

<ResponseField name="id" type="integer">
  Unique identifier for the category.
</ResponseField>

<ResponseField name="name" type="string">
  Human-readable category name (e.g. `"Music"`, `"Sports"`, `"Food"`).
</ResponseField>

```json
[
  { "id": 1, "name": "Music" },
  { "id": 2, "name": "Sports" },
  { "id": 3, "name": "Food" },
  { "id": 4, "name": "Adventure" },
  { "id": 5, "name": "Outdoors" }
]
```
